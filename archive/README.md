# 이전 자료 보관

`legacy/`는 2026-10-01 재구성 직전의 실제 작업 디렉터리를 보존한 것입니다. 사용자가 이미 변경하신 파일도 포함하며 Git의 이전 커밋으로 되돌리지 않았습니다. 이동 전후 647개 파일의 SHA256을 비교했습니다. 목록은 `legacy/ARCHIVE_MANIFEST.json`입니다.

- `legacy/ai-interior/`: 이전 메인 코드, 실험, 개발 일지와 샘플
- `legacy/presentation/`: 이전 발표 자료와 제작 소스
- `legacy/ai_interior.md`: 이전 설계·작업 규칙
- `legacy/Output/`: 당시 남아 있던 출력 폴더
- `reference/`: 사용자의 원래 기획 PDF 및 기능 예시 PPTX

현재 실행은 최상위 `app.py`와 `roomfit/`를 사용합니다. 보관 자료의 API 경로와 규칙은 현재 기능이나 작업 지침이 아닙니다. 이전 성능 수치를 현재 생성 모델의 측정값으로 인용하지 않습니다.

기존 파일을 근거로 한 독립 검토 원문과 판정은 [초기 검토](../docs/reviews/2026-10-01-initial-critique.md)에 있습니다.
